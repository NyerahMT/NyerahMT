## Fluid Engine Swift

An older Swift / Metal fluid simulation project I found and brought back into a working state.

The simulation uses **Metal compute shaders** for GPU-side computation and **Grand Central Dispatch** for parallel work on the CPU side.

I mostly picked it up because GPU compute looked interesting and I wanted to understand what the implementation was actually doing.
