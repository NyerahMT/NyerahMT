I work in nuclear fabrication and spend a significant amount of my free time digging into software, simulation, mechanics, and systems that are interesting enough to warrant understanding from the inside out.

My development work tends to involve existing systems with actual complexity: platform ports, rendering, physics, performance, input systems, application lifecycle behavior, GPU compute, and debugging code that was never designed for the platform I'm putting it on.

I'm particularly interested in the point where software stops being abstract and starts representing a physical system.
